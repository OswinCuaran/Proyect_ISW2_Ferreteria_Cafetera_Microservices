# Pruebas de rendimiento

Aquí van las pruebas de rendimiento hechas con Locust. Cada integrante define y ejecuta un mínimo de quince pruebas sobre endpoints de distintos microservicios, en escenarios de carga normal, carga pico y estrés.

Todas las pruebas se hacen a través del API Gateway, que es la única entrada al sistema. En cada una se mide el tiempo de respuesta, el número de peticiones por segundo y la tasa de error.
